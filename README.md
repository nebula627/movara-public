# Movara

Your movies and TV shows, together in one place.

Movara is a personal media server and playback experience for organizing and watching your own media library. Run the server on a computer you control, add your media folders, and connect through a web browser or a compatible Movara client. Your library stays on your server; Movara does not provide movies or TV shows.

## What Movara does

- **Organize your library:** Scan your movie and TV folders and browse titles, seasons and episodes from one interface.
- **Discover what to watch:** Explore library artwork, descriptions and other available metadata, search your collection, and return to titles you have started.
- **Watch on your devices:** Use the web interface or Movara's Android phone and TV clients to connect to your server and play your media.
- **Manage access:** Create server accounts and manage access from the administrator dashboard. Available permissions depend on the server version.
- **Connect optional services:** Configure supported metadata providers and optional services such as Sonarr, Radarr and Prowlarr. These are separate services and may require their own setup or credentials.
- **Adapt playback:** Compatible installations can use FFmpeg for media inspection and playback conversion when a device cannot play a source format directly.

Metadata availability, playback formats, subtitles and surround sound depend on the media file, server configuration, connected device and audio equipment.

## How it works

1. Install and configure a Movara server on a suitable computer.
2. Add folders containing media you are authorized to use.
3. Create an account and configure any optional integrations.
4. Connect from a browser or Movara client using the server's local network address or a properly configured public HTTPS address.

A working server, network connection and compatible media are required. For access outside your home, you are responsible for securely configuring your server and HTTPS connection.
